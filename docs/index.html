Kimai
Abrechnung

Kimai plugin for a billing overview. Shows all billable, not yet exported timesheet entries, grouped by customer and project.

Kimai-Plugin für die Abrechnungsübersicht. Zeigt alle abrechenbaren, noch nicht exportierten Zeiteinträge – gruppiert nach Kunde und Projekt.

cd /var/plugins/ && git clone https://github.com/shrippen/kimai-abrechnung-bundle.git AbrechnungBundle && docker restart kimai_app

Or copy the AbrechnungBundle folder to /var/plugins/ and restart the container or run bin/console cache:clear --env=prod. The menu item “Abrechnung” appears under “Rechnungen”.

Oder kopiere den Ordner AbrechnungBundle nach /var/plugins/ und starte den Container neu oder führe bin/console cache:clear --env=prod aus. Der Menüpunkt „Abrechnung“ erscheint unter „Rechnungen“.

Technology

Technik

  • No own database — uses the existing exported flag of the timesheet entity
  • AJAX endpoint — POST /de/abrechnung/mark with X-Requested-With: XMLHttpRequest
  • Persistence — TimesheetService::saveTimesheet(), the same code path as Kimai’s export button
  • Rollback — delete the plugin folder and restart the container; no migrations needed
  • Keine eigene Datenbank – nutzt das vorhandene exported-Flag der Timesheet-Entität
  • AJAX-Endpunkt – POST /de/abrechnung/mark mit X-Requested-With: XMLHttpRequest
  • Persistenz – TimesheetService::saveTimesheet(), derselbe Codepfad wie beim Export-Button von Kimai
  • Rollback – Plugin-Ordner löschen und Container neu starten; keine Migrationen nötig
