Kimai
Abrechnung

Kimai plugin for a billing overview. Shows all billable, not yet exported timesheet entries, grouped by customer and project.

Kimai-Plugin für die Abrechnungsübersicht. Zeigt alle abrechenbaren, noch nicht exportierten Zeiteinträge – gruppiert nach Kunde und Projekt.

git clone https://github.com/shrippen/kimai-abrechnung-bundle.git var/plugins/AbrechnungBundle && bin/console cache:clear --env=prod

The menu item “Billing” (German: “Abrechnung”) then appears under “Invoices”. In Docker, run the console command as docker exec -it CONTAINER /opt/kimai/bin/console cache:clear --env=prod, or restart the container. To update: git pull in the plugin folder, then clear the cache again.

Der Menüpunkt „Abrechnung“ erscheint danach unter „Rechnungen“. In Docker führst du den Konsolenbefehl als docker exec -it CONTAINER /opt/kimai/bin/console cache:clear --env=prod aus oder startest den Container neu. Zum Aktualisieren: git pull im Plugin-Ordner, danach den Cache erneut leeren.

All open entries

“Visible” means after your filter. Narrow it first, and the actions only touch what you see. Nothing reloads: each click is a request in the background, and billing twice changes nothing.

Technology

Technik

  • No own database — uses the existing exported flag of the timesheet entity
  • Query — TimesheetRepository::getTimesheetsForQuery(), including team permissions, like Kimai’s own lists
  • Endpoint — POST /de/abrechnung/mark with ids[], action=mark|unmark and a CSRF token; it sets the status instead of toggling it, so it is idempotent
  • Persistence — TimesheetService::saveTimesheet(), the same code path as Kimai’s API endpoint PATCH /api/timesheets/{id}/export
  • Rollback — delete the plugin folder and restart the container; no migrations needed
  • Keine eigene Datenbank – nutzt das vorhandene exported-Flag der Timesheet-Entität
  • Abfrage – TimesheetRepository::getTimesheetsForQuery(), inklusive Team-Berechtigungen, wie Kimais eigene Listen
  • Endpunkt – POST /de/abrechnung/mark mit ids[], action=mark|unmark und CSRF-Token; er setzt den Status, statt ihn umzuschalten, und ist damit idempotent
  • Persistenz – TimesheetService::saveTimesheet(), derselbe Codepfad wie Kimais API-Endpunkt PATCH /api/timesheets/{id}/export
  • Rollback – Plugin-Ordner löschen und Container neu starten; keine Migrationen nötig

Questions

Fragen

Does it change my data?Ändert es meine Daten?

It only sets the exported flag that Kimai already has on every timesheet entry, through the same code path as Kimai’s own API endpoint for the export flag. Nothing else is written.

Es setzt nur das Flag exported, das Kimai an jedem Zeiteintrag ohnehin hat, über denselben Code-Pfad wie Kimais eigener API-Endpunkt für das Export-Flag. Sonst wird nichts geschrieben.

Which entries are listed?Welche Einträge werden angezeigt?

Every entry that is billable, not yet exported and finished. Running entries and entries you already billed do not appear in the open list; switch the status to Billed or All to see them.

Jeder Eintrag, der abrechenbar, noch nicht exportiert und beendet ist. Laufende Einträge und bereits abgerechnete Einträge erscheinen nicht in der offenen Liste; stelle den Status auf Abgerechnet oder Alle, um sie zu sehen.

Can I undo a billing?Kann ich das Abrechnen zurücknehmen?

Yes. Right after billing, the notice offers Undo for 15 minutes. Later, switch the status to Billed and use Reopen; that needs the permission edit_exported_timesheet.

Ja. Direkt nach dem Abrechnen bietet der Hinweis 15 Minuten lang Rückgängig. Später stellst du den Status auf Abgerechnet und nutzt Zurücknehmen; dafür brauchst du das Recht edit_exported_timesheet.

How do I remove it?Wie entferne ich es?

Delete the plugin folder and restart the container. There are no database migrations to revert.

Lösche den Plugin-Ordner und starte den Container neu. Es gibt keine Datenbank-Migrationen, die zurückgenommen werden müssten.
